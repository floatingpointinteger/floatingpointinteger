### Digital Logic & RTL

**[nand_to_alu](https://github.com/floatingpointinteger/nand_to_alu)**

A **4-bit ALU implemented from NAND-gate primitives** in Digital Logic Sim, supporting **ADD, SUB, NOT, and INC** through decoder-based opcode selection.

Built bottom-up without pre-built components — from individual gates through full adders, a 4-bit adder, and control logic.

---

### Software Foundations

**[calculator](https://github.com/floatingpointinteger/calculator)**

A Java expression evaluator with custom parsing, operator precedence, exponentiation, unary operators, floating-point literals, and syntax validation.

Includes a **171-case test suite** covering the parser and evaluator.

---

### Underwater Wireless Modem

**[underwater_wireless_modem](https://github.com/floatingpointinteger/underwater_wireless_modem)**

A real-time underwater wireless modem with custom signal decoding, frequency-based signaling, adaptive detection, and UART-like packet decoding.

Uses `sounddevice` callbacks and queue-based audio buffering for concurrent data handling.
